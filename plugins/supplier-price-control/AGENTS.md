# Контроль закупок (supplier-price-control)

Настройки — в блоке «Настройки» внутри каждого скилла.

## Автоиспользование

- Скиллы и MCP плагина подключай **без** явного `@`/упоминания, если запрос пользователя попадает в таблицу ниже или в `description` скилла.
- Почтовые действия выполняй **только** через bundled MCP `mail-mcp` (`list_accounts`, `sendMessage`, `searchMessages` и др.), не имитируй отправку текстом.
- Не спрашивай «использовать ли MCP» — вызывай инструменты сразу по алгоритму скилла.

| Ситуация                                     | Скилл                    |
| -------------------------------------------- | ------------------------ |
| Номенклатурная позиция в чате                | `wholesale-offer-search` |
| Отправить запрос на формирование КП          | `send-supplier-email`    |
| Проверить почту / inbox / ответы поставщиков | `check-mailbox-replies`  |
