# Поиск оптовых предложений

## Настройки

Считать оффер «выгоднее текущей цены», если цена за закупаемую единицу по предложению ниже текущей.

Искать только оптовые предложения для B2B

Валюта RUB рубли

Выполнять тщательный веб-поиск предложений и валидировать корректность результатов

Запрещено выдумывать факты и предлагать заведомо неверные результаты.

Лишних вопросов не задавать. Вести взаимодействие с пользователем кратко и по делу

## Алгоритм действий

1. Из сообщения: извлечь присланную информацию об номенклатурной позиции.
2. Произвести веб поиск существующих предложений по данной позиции
3. Краткий отчёт по выполненному поиску в виде таблицы с одим предложением в виде вывода. Показать найденные предложения в виде таблицы без лишних слов. В таблицу включить источник с корректной веб ссылкой, Стоимость за единицу товара с показателем насколько процентов выгоднее/невыгоднее закупать у этого поставщика в процентах от текущей цены, Контактную информацию поставщика. Для очевидно невыгодных найденных предложений - написать кратко в отчете текстом о них, указать что они невыгодные, приложить веб-ссылки.
4. Предложить пользователю отправить email с запросом КП для выбранных им контрагентов через skill send-supplier-email
