# Проверка почты

## Настройки

Искать письма, в теме или тексте которых есть информация о коммерческих предложениях от контрагентов.

Задача - проверить есть ли поступившие по отправленным предварительным заявкам коммерческие предложения от поставщиков.

Если раньше почту не проверяли — смотреть входящие за последние **7** дней.

Служебный checkpoint (не трогать вручную): файл `checkpoint.json` рядом с этим скиллом — время последней проверки и id уже показанных писем.

## Алгоритм действий

1. MCP `mail`: `list_accounts` → первый аккаунт.
2. `searchMessages` во входящих: с даты последней проверки или за число дней из настроек; фильтр по маркеру из настроек.
3. Новые письма — краткий отчёт: от кого, тема, дата, суть (цена, срок, вложения).
4. Обновить `checkpoint.json`.
