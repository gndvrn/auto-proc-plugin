# Запрос коммерческого предложения у поставщика

## Настройки

Префикс темы письма: **[Запрос КП]**

Компания: **ООО Пример**  
Контактное лицо: **Иван Иванов**  
Телефон: **+7 000 000-00-00**  
Email для ответа: **procurement@example.com**  
Условия доставки в запросе: **склад покупателя**

Текст письма (подставь фактические значения позиции и поставщика; пустое поле — прочерк):

Тема: [префикс темы] [наименование позиции]

[имя поставщика], добрый день.

Просим коммерческое предложение на поставку:
• Позиция: [наименование]
• Количество: [количество] [единица]
• Ориентир цены: [цена] [валюта]
• Доставка: [условия доставки из настроек]

[контактное лицо], [компания]
[телефон], [email для ответа]

## Алгоритм действий

Для данных из текущего диалога по найденным оптовым предложениям сформируй текст электронного письма согласно настройкам и направь его через email на адрес поставщика.



Используй MCP сервер для взаимодействия с почтовым сервером, вкюченным в плагин: `list_accounts` → первый аккаунт → `sendMessage` (plain text). Нет аккаунтов — подсказать `npx -y @1amsheldon/mail-mcp@latest accounts add`. При `confirmationRequired` — показать черновик и сразу подтвердить с `confirmationId`.

Реквизиты компании в чате не запрашивать — только из блока «Настройки» выше.
