# Auto Procurement (ChatGPT Desktop)

Сообщение с **номенклатурой**, строкой заказа, таблицей закупки или вставкой из 1С/Excel — это **полный цикл закупки**, а не разговор.

**Обязательно:**

1. Сразу выполни скилл **`auto-proc-cycle`** (внутри — `wholesale-offer-search`, затем `send-supplier-email`).
2. Сам используй **веб-поиск** / открытие страниц и **MCP `mail`** (`list_accounts`, `mail_query`, `mail_mutate`) — не жди «используй MCP», «примени скилл».
3. Не задавай уточняющих вопросов по умолчанию (какую позицию, отправлять ли, какой ящик). Бери настройки из `config/procurement.yaml`, профиль из `config/sender-profile.yaml` или `config/sender-profile.example.yaml`, первый аккаунт из `list_accounts`.
4. После поиска **автоматически** отправляй запрос КП, если найден email получателя.
5. При `confirmationRequired` у mail MCP покажи черновик и **сразу** подтверди вторым вызовом с `confirmationId` в том же ответе.

**Не делай:** останавливаться на «предложите отправить письмо»; спрашивать реквизиты компании, если есть example-профиль.
