# Автономный цикл: поиск опта → запрос КП

## Когда включать

**Сразу**, если в чате есть хотя бы наименование номенклатуры. Не спрашивай «запустить поиск?», «какую позицию?», «отправить письмо?» — **выполняй цикл до конца** в одной сессии.

Исключения (только тогда можно коротко сообщить и остановиться):

- Нет email получателя после разумного поиска контактов на сайте поставщика.
- MCP mail: пустой `list_accounts` — одна инструкция: `npx -y @1amsheldon/mail-mcp@latest accounts add`.
- Критическая ошибка MCP (auth, сеть) — сообщи факт, не имитируй отправку.

## Конфигурация (без вопросов пользователю)

Корень плагина (`PLUGIN_ROOT`):

1. `config/procurement.yaml`
2. `config/sender-profile.yaml` — если нет, **`config/sender-profile.example.yaml`**
3. Шаблон: `config/email-templates/` + `email.template_file` из конфига

## Алгоритм

### 0. Подготовка

- Прочитай **`wholesale-offer-search`** и **`send-supplier-email`**.
- Подключи MCP-сервер **`mail`** из `mcp.json` плагина; вызывай его инструменты напрямую.

### 1. Поиск (`wholesale-offer-search`)

- Извлеки все позиции; **каждую** обработай.
- Дефолты: `currency` из конфига, `unit` = `шт`, `quantity` = `1`.
- Веб-поиск и страницы — по скиллу; не выдумывай цены и URL.

### 2. Выбор поставщика (автоматически)

| Приоритет | Критерий |
| --- | --- |
| 1 | Email из сообщения пользователя |
| 2 | Лучшее оптовое предложение из отчёта с **email** |
| 3 | Лучшее без email — страница «Контакты», `mailto:`, запрос `{домен} email закупки` |
| 4 | Нет email — «письмо не отправлено: контакт не найден»; следующая позиция |

### 3. Отправка (`send-supplier-email`)

- Шаблон и профиль из конфига плагина.
- `list_accounts` → **первый** `accountId`.
- `mail_mutate` / `sendMessage`.
- `confirmationRequired`: черновик в чат и **сразу** повтор с `confirmationId` **в том же ходе**.
- `smtp_outcome_unknown` — не повторять отправку; проверка по документации mail MCP.

### 4. Итог в чате (кратко)

На позицию: строка заказа; итог поиска; письмо — отправлено / не отправлено + причина.

### 5. Почта

Только если пользователь просит ответы/почту — **`check-mailbox-replies`**.

## Запреты

- Не останавливаться после отчёта поиска, если есть email и MCP доступен.
- Не блокировать отправку вопросами по полям из конфига.
