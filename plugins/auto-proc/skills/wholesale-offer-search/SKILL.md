# Поиск более выгодных оптовых предложений

## Конфигурация

Прочитай `config/procurement.yaml` в корне плагина. Пороги и шаблоны поиска — только оттуда. **Не** спрашивай пользователя про пороги.

## Шаг 1 — позиция заказа

| Поле | Описание |
| --- | --- |
| `nomenclature` | Наименование |
| `unit_price` | Цена за единицу (если нет — сравнение между найденными оптами) |
| `quantity` | Если нет — `1` |
| `currency` | Если нет — `search.currency_default` |
| `unit` | Если нет — `шт` |

**Несколько позиций** — все отдельными блоками; приоритет **не** уточняй.

## Шаг 2 — поиск

**Встроенный веб-поиск ChatGPT** и открытие страниц. Не выдумывай URL и цены.

1. До `search.max_queries` запросов из `search.query_templates`.
2. Только **опт/B2B** (розницу помечай, в сравнение по умолчанию не включай).
3. На кандидата: источник, цена за единицу, валюта, MOQ, **url**, email/`mailto` если есть.

«Выгоднее» при экономии ≥ `search.min_savings_percent`.

## Шаг 3 — отчёт

Кратко: позиция, кол-во, ваша цена (если была). Таблица по `offers_report` при наличии выгодных офферов.

## После отчёта

**Не** предлагай «отправить письмо?» — **`auto-proc-cycle`** сам вызывает **`send-supplier-email`**.
