# Поиск опта дешевле

**Настройки (правь здесь):** РФ · только **опт/B2B** (розницу не сравнивать) · валюта `RUB` · порог экономии **0%** · до **~35** запросов веб-поиска и **~8+** открытий страниц на позицию · в отчёте до **8** строк.

## Алгоритм

1. Из текста пользователя: название, цена за ед., кол-во, валюта. Несколько позиций — отдельный мини-отчёт на каждую.
2. **Веб-поиск:** шаблоны вида «{номенклатура} + опт/B2B/дистрибьютор/прайс/для юрлиц»; плюс свои запросы (артикул, бренд, `site:`) — всегда с «опт»; вторая волна, если мало оптовых цен.
3. **Открывай** карточки и прайсы. Цены только с сайта; оптовая колонка, не розница. URL и цифры не выдумывать.
4. В чат **только финал**, без хода поиска:
   - `Позиция: … · ваша цена …`
   - `Итог: …` (выгоднее опт / не найдено; если была только дешёвая розница — одной фразой «розница не в сравнении»)
   - таблица: **поставщик | цена | −% | url**
   - Для выгодных предложений, если такие есть предложи послать email
